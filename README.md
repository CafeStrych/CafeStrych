# CafeStrych v2
1. Najpierw uruchom cały plik `supabase/upgrade_v2.sql` w Supabase SQL Editor.
2. Sprawdź Table Editor > profiles: konto Daniela powinno mieć `role = admin`. Jeśli nie, ustaw je ręcznie na `admin`.
3. Wgraj całą zawartość folderu do katalogu głównego repozytorium GitHub `CafeStrych`.
4. Nie zmieniaj `config.js`, jest już uzupełniony.
5. Odśwież stronę z pominięciem pamięci podręcznej.

Logo zastosowane w interfejsie jest autorskim emblematem tekstowym, a nie kopią oficjalnego znaku. Oficjalne logo można później podmienić po dostarczeniu pliku od właściciela.
