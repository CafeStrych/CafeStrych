# CafeStrych
## GitHub
Wgraj zawartość tego folderu do katalogu głównego repozytorium `CafeStrych` i zatwierdź zmiany. GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).
## Rejestracja w Supabase
1. Authentication > Providers > Email.
2. Włącz Email provider oraz Allow new users to sign up.
3. Pozostaw Confirm email włączone, jeśli każdy ma potwierdzać adres.
4. Authentication > URL Configuration: ustaw Site URL i Redirect URL na dokładny adres GitHub Pages repozytorium CafeStrych.
5. Jeżeli po utworzeniu konta nie pojawi się rekord w `profiles`, uruchom `supabase/registration_check.sql` w SQL Editor.
## Logo
Emblemat w aplikacji jest autorskim znakiem tekstowym inspirowanym klimatem starej chaty rybackiej. Nie jest kopią oficjalnego logo. Oficjalne logo można dołączyć po dostarczeniu pliku, do którego właściciel lokalu ma prawa.
